# Business Analytics: Weekly Assignments

> **Academic notice:** This repository is created **only for university submission purposes**. It holds my weekly Business Analytics assignments for the BCA programme at Alliance University, Bangalore (Semester V). It is not a standalone project. Please do not copy this work for your own submissions.

## What is in this repository

Six weekly assignments, each in its own folder with a Power BI file (`.pbix`) and a PDF report. Each report states the problem, the dataset, the steps followed and the results.

| # | Assignment | Main topic |
|---|---|---|
| 1 | Importing Business Datasets from Flat Files and MySQL, and Connecting Other Sources into Power BI | Getting data into Power BI |
| 2 | Creating Power BI Visualizations to Analyze Sales Performance Across Products, Categories and Regions | Charts for sales analysis |
| 3 | Building a Dashboard: Analyzing Sales, Revenue, Profit and Product Performance | Dashboard design |
| 4 | Data Cleaning using Power Query | Fixing missing values, duplicates and inconsistent entries (Cafe Sales dirty data) |
| 5 | Building Customer Analysis Dashboard | Customer, sales, revenue and profit analysis |
| 6 | Sorting and Filtering Data | Finding high-value transactions and underperforming products |

## Tools

Power BI Desktop, Power Query, Excel and CSV files, MySQL.

## How to open the files

1. Clone the repository:
   ```bash
   git clone https://github.com/anuskaGHS/Business-Analytics.git
   ```
2. Open a folder such as `Weekly Assignment 5` and read the PDF report first.
3. To explore the dashboard, open the `.pbix` file in Power BI Desktop (a Windows application). Some files may ask you to point to the original data source.
